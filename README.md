FatApp
FatApp este o aplicatie Android pentru monitorizarea progresului personal si a activitatii fizice.

Functionalitati
Inregistrarea greutatii si vizualizarea istoricului.

Calcularea si afisarea indicelui de masa corporala (BMI).

Monitorizarea pasilor zilnici.

Inregistrarea automata a activitatii de mers.

Vizualizarea tendintelor si a unei estimari pentru evolutia greutatii.

Exportarea si distribuirea raportului de evolutie.

Salvarea datelor local pe dispozitiv.

Tehnologii
Kotlin

Android Jetpack Compose

Room Database

Health Connect

Android Step Counter Sensor

Material 3

Rulare locala
Cloneaza repository-ul:

bash
git clone https://github.com/skipsalajan/FatApp.git
Deschide proiectul in Android Studio.

Sincronizeaza proiectul cu Gradle.

Ruleaza aplicatia pe un dispozitiv Android compatibil.

Pentru monitorizarea pasilor, aplicatia are nevoie de permisiunea Android pentru activitate fizica. Rezultatele pot varia in functie de dispozitiv si de senzorii disponibili.
